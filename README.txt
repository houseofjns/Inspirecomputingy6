BILINGUAL LEARNING PORTAL + UNIT EXAMINATION SYSTEM

============================================================
1. OPEN THE PORTAL
============================================================

1) Extract this ZIP archive.
2) Open index.html in a modern browser.
3) Enter the student name and portal access password.
4) Open Course Units to study the six units.

The website uses HTML, CSS and vanilla JavaScript. Learning notes,
visual materials, quizzes and the examination engine are stored locally.
For service-worker offline caching, serve the project through localhost
or HTTPS. Opening index.html directly still supports the local portal,
but service-worker installation is browser restricted.

For GitHub Pages, upload the extracted project contents to a repository
and enable GitHub Pages for the chosen branch/folder.

3. YEAR 6 SOURCE COVERAGE
============================================================

The portal content was created from the uploaded:
- Inspire Computing International Year 6 Student Book (Pearson).
- Inspire Computing International Year 6 Workbook (Pearson).
- Inspire Computing Year 6 Workbook Answers.

IMPORTANT FILE-SIZE NOTE:
The original Student Book PDF, Workbook PDF, Answer PDF and scanned PDF
page images are NOT bundled in this ZIP. The verified answer text from
the supplied answer guide is included in js/workbook-answers.js, and the
teaching visuals are recreated as local SVG / HTML / CSS components.

The six-unit sequence follows the Student Book contents:

Unit 1  Databases
  Looking at ways to store information; creating a data table and
  running basic queries; using spreadsheet software with a single-table
  database; database use in school and outside school; database
  management systems; searching online databases; online research;
  reviewing research findings.

Unit 2  Programming (part 1)
  Introduction to algorithms; algorithms using loops; programming
  solutions with loops; a Frogger-style game; movement of game objects
  and forever loops; IF…THEN interaction; variables and scoreboards;
  alpha and beta testing; completing and reviewing a game.

Unit 3  Networks in society
  Impacts of technology; information services; research planning and
  reporting; class surveys; physical and online social networking;
  staying safe on social networking sites; code of conduct.

Unit 4  Video editing
  Staging; sound; on-screen text; planning and storyboarding; shooting;
  editing clips; safe and responsible video use.

Unit 5  Health and safety
  Computing-device features; injuries and ergonomics; videos about safe
  use; environmental impact; smartphone life cycle; reducing e-waste;
  planning, designing and presenting a leaflet.

Unit 6  Programming (part 2)
  Designing, testing and repurposing algorithms; loops; variables;
  repurposing programs; programming a timer; drawing 2D shapes;
  multiple shapes; coordinates; representing objects with shapes.

Every unit has 15 learning sections, including bilingual study notes,
lesson-by-lesson topic explanations, definitions, examples, tables,
diagrams, step-by-step work, practical activities, workbook answer
support, exam points, glossary, slide outline, quiz and unit exam.

4. VISUAL STUDY NOTES
============================================================

Each of the 60 lessons includes one or more visual learning items:
- Database structure diagrams, data tables and query process flows.
- Algorithm flows, robot routes, Scratch-style code / block logic.
- Survey tables and sample charts, online-safety decision flows.
- Storyboards, camera and video-editing process diagrams.
- Device comparison tables, ergonomics and smartphone life-cycle flows.
- Scratch timer logic, Pen extension, shape angles and coordinate grids.

Scratch-style logic and pseudocode are learning examples; this project
does not contain an editable Scratch project file. Any illustrative
sample figures are labelled as practice examples.

============================================================
6. QUIZZES AND EXAMINATIONS
============================================================

Each unit has a formative 10-question practice quiz with instant
feedback, score and retry.

Each unit also has an independent 60-minute, 100-mark examination:
A. 30 Multiple Choice questions  = 30 marks
B. 20 Fill in the Blanks          = 20 marks
C. 20 Matching questions          = 20 marks
D. 10 Short Questions             = 10 marks
E.  4 Long Questions / Essays     = 20 marks
TOTAL: 84 questions               = 100 marks

Exam password: HJS2026

The exam engine includes forward-only question navigation, question
locking, fullscreen requests, before-unload warning and automatic
submission at the time limit. Correct answers are shown only after
submission. Essays receive provisional keyword-based marks and a teacher
review flag; teachers should review open-ended answers.

Browser-only JavaScript cannot guarantee tamper-proof lockdown. A browser
or device may restrict fullscreen requests, and it cannot fully prevent
screen switching, developer tools or all navigation methods. For high-
stakes exams, use a managed server-based exam platform.

============================================================
7. RESULTS AND LOCAL DATA
============================================================

Exam results and learning progress are stored in the current browser's
local storage. They remain on that device/browser and are not synced to
other devices. Clearing browser site data may remove the saved results.

The result page displays total score, percentage, pass threshold,
section breakdown and student-answer versus correct-answer review.

============================================================
8. TROUBLESHOOTING
============================================================

- If the logo does not appear, check assets/logo1.png is present.
- Keep the css, js and assets folders beside index.html.
- Do not rename the JavaScript files referenced in index.html.
- If offline cache looks outdated, reload the page after closing old tabs.
- If fullscreen is unavailable, continue using the displayed browser
  warning and the on-screen Next Question control.
